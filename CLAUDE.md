# Jury Duty

A browser courtroom game in plain HTML, CSS and JavaScript with no build step. See `README.md` for how to play and how to add cases.

## Agent skills

### Issue tracker

Issues are tracked in this repo's GitHub Issues (mdbatey/Jury-duty). See `docs/agents/issue-tracker.md`.

### Triage labels

The default five labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
